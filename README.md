## Other Projects

### HTTP from TCP --- HTTP Protocol Parsing in Go

A low-level networking project exploring how HTTP messages are carried
over TCP and how application code can parse a request from the byte
stream.

**What it demonstrates** - Working with TCP connections and byte
streams. - Parsing HTTP request components such as the method,
target/URL, headers, and body. - Understanding the boundary between the
transport layer (TCP) and the application layer (HTTP). - Exploring why
TCP provides an ordered byte stream rather than separate, pre-defined
HTTP messages.

**Repository:**
[httpfromtcp](https://github.com/dhinesh20022806/httpfromtcp)
